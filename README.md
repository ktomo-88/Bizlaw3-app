# ビジ法3級 一問一答アプリ

2026年11月6日のビジネス実務法務検定3級向け、弱点集中型の一問一答Webアプリです。

## 収録
- 60問
- 意思表示 / 代理 / 条件・期限 / 弁済 / 契約 / 不法行為 / 財産管理 / 債務不履行 / 時効 / 担保
- 問題・解説は、提供されたTAC 2026年度3級基本テキストで確認した論点を中心にオリジナル化

## 主な機能
- 今日の復習
- 弱点だけ
- 全分野ランダム
- 分野別
- 模擬20問
- 誤答・怪しい問題の管理
- 1→3→7→14→30日の復習間隔
- 分野別正答率
- localStorageによる学習履歴保存
- JSONバックアップ / 復元
- PWA / オフラインキャッシュ

## iPadで使う最短方法：GitHub Pages
1. GitHubで新しいリポジトリを作る
2. このフォルダ内のファイルをすべてアップロード
3. Settings → Pages
4. Deploy from a branch を選択
5. main / root を選び Save
6. 表示されたURLをiPadのSafariで開く
7. Safariの共有ボタン →「ホーム画面に追加」

これで通常のアプリに近い感覚で使えます。

## PCがある場合のローカル起動
このフォルダで次を実行します。

```bash
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開きます。

## 注意
ChatGPTアプリ内のHTMLプレビューではJavaScriptが動かない場合があります。
通常のSafari / Chrome上で、GitHub Pages等のHTTP(S)環境から利用してください。

## 問題追加
`questions.js` の `window.QUESTIONS` 配列へ同じ形式のオブジェクトを追加します。
既存の `id` は学習履歴と結びつくため変更しないでください。
