## 重要：アップロード前にバックアップ
v3アプリの「学習データを書き出す」からJSONのバックアップを取り、iPadの「ファイル」に保存してください。
ホーム画面の既存アイコンは**削除せず**、GitHub上の同じリポジトリへv4のファイルを同名上書きアップロードしてください。

## iPadからのGitHub更新
1. ZIPをファイルアプリで展開
2. GitHubで `Bizlaw3-app` リポジトリの `Code` タブを開く
3. `Add file` → `Upload files`
4. 展開フォルダ**内の以下のファイル**をアップロード（フォルダ自体を置くのではない）
5. `Commit changes` を実行。GitHub Actionsの `pages build and deployment` が緑になるのを確認
6. ホーム画面の既存アプリを閉じて再起動。古い場合はSafariでサイトを開き再読み込み

アップロードするファイル：`index.html`, `style.css`, `app.js`, `questions.js`, **`flashcards.js`（新規）**, `manifest.webmanifest`, `service-worker.js`, `icon-192.png`, `icon-512.png`。`README.md` も任意で更新できます。
