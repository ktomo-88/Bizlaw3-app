# ビジ法3級 一問一答 v3

## v3の変更点
- 60問 → 120問
- 「民法特訓」を追加
- 「第5回 復習」を追加
- 第5回（約定担保・人的担保・商行為・商業登記・会社）を30問追加
- 民法横断（相殺・債権譲渡・即時取得・解除・契約不適合・請負）を30問追加
- 問題に domain / lecture タグを追加
- v2と同じ localStorage キーを維持し、既存IDも変更していないため学習履歴を引き継ぐ
- 未学習問題を「今日の復習」に大量表示しないよう改善
- 実際に誤答した問題は、解説後に「分かった」を押しても翌日再確認する仕様に改善
- PWAキャッシュを v3 に更新

## 学習の使い分け
- 毎日最初：今日の復習
- 民法強化：民法特訓
- 講義第5回の定着：第5回 復習
- 本番対応：模擬20問＋TAC/成美堂の通常問題
